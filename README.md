## Как устроен репозиторий

```
people/*.md                  карточки персон, по одному файлу на человека
tree/tree.md                 древо + mermaid-схема прямой линии + разбор конфликтов
tree/timeline.md             хронология событий семьи с историческим контекстом
research/log.md              лог: что проверено, где, с каким результатом
research/open-questions.md   пробелы и конфликты по приоритету
research/search-plan.md      план поиска + 5 шаблонов запросов
sources/sources.md           реестр источников (src-NNN)
GENEALOGY_TASK.md            техническое задание проекта
public/index.html            веб-приложение древа (исходная база, src-001)
```

## Правила маркировки

- **[ФАКТ]** — есть источник, источник указан.
- **[ГИПОТЕЗА]** — указано основание и вероятность (высокая / средняя / низкая).
- **[ПРОБЕЛ]** — неизвестно, вынесено в `research/open-questions.md`.

На сегодня **фактов в проекте нет ни одного**: вся база — семейная запись без документального подтверждения,
поэтому каждое утверждение помечено как гипотеза с источником `src-001`. Первый же ответ из архива
переведёт часть строк в статус [ФАКТ].

Разночтения имён сохраняются все и не правятся молча: `Саловьев / Соловьёв`, `Бондоренко / Бондаренко`.
