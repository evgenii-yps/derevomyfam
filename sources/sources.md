## Шаблон строки для архивного дела

```
| src-0NN | метрическая книга | ГА<регион>, ф. <N>, оп. <N>, д. <N>, л. <N> об., запись № <N> | ГГГГ-ММ-ДД | рождение <ФИО>, имя отца, сословие, приход | высокая |
```

## Правила ведения

1. **Ни одно утверждение в карточке персоны не остаётся без `src-`.** Если источника нет — ставится `[ПРОБЕЛ]`, а не пустота.
2. Для онлайн-баз указывается URL **и** дата обращения: базы меняются и исчезают.
3. Для архивного дела указывается полный шифр: архив → фонд → опись → дело → лист → номер записи. Без шифра результат невоспроизводим.
4. Отрицательный результат («в фонде N за 1893 г. записи о рождении Флегонтова Ивана нет») фиксируется наравне с положительным — иначе поиск пойдёт по второму кругу.
5. Скан/фото документа кладётся в `sources/scans/<src-NNN>.<ext>`, если позволяют права.
